### Step 1: Check for Existing Testbench

Look in the designs.json for testbench files associated with this design:
- Load `{{OUTPUT_DIR}}/designs.json`
- Find the design entry for this folder
- Check if `testbench_files` is non-empty

If an existing testbench is found:
1. Copy it to `{{DESIGN_DIR}}/tb.cpp`
2. Update any include paths to work with the flat structure
3. Verify it references the correct kernel function
