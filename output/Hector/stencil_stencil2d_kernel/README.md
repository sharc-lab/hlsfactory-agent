# 2D Stencil Computation Kernel

## Description
Two-dimensional stencil computation kernel.
Common in scientific computing applications such as image processing and PDE solvers.

## Top-Level Function
- Name: `main`
- Design: `stencil`
- Return Type: void

## Framework
HECTOR - MLIR-based hardware synthesis framework.

## Source Files
- `design.mlir` - MLIR TOR dialect representation

## Algorithm
2D stencil with neighbor operations for grid-based computations.
